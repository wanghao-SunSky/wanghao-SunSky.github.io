# 网站设计规范

SunSky 的 AI Agent 工程笔记以中文长文为主。首页直接呈现作者简介和文章，阅读页把宽度留给正文。浅色的纸面、宋体的粗细搭配和胶囊导航取自[妙言中文站](https://miaoyan.app/zh/)。

## 中文排版

正文、标题和界面共用 `"Blog Serif SC", Charter, Georgia, "Songti SC", serif`。常规中文字重 400 用屏显臻宋 v1.10，字重 500 至 700 用思源宋体 SC SemiBold。中文弯双引号和省略号也由宋体排印。拉丁字母和数字优先用 Charter，其次用 Georgia。代码用 `"SF Mono", "JetBrains Mono", Menlo, Consolas, monospace`。

桌面日期和目录用 14px，导航和摘要用 15px，正文用 16px，二级标题用 21px，一级标题用 32px。手机上一级标题收至 26px。正文栏最宽 720px，普通行高 1.75，文章行高 1.8，手机文章行高 1.7。正文左对齐，字间距 0.03em，标题字间距 0.01em，手机标题归零。导航、页脚、日期、按钮和代码字间距为零。日期使用等宽数字，中文行末标点允许悬挂。

## 页面与组件

- 导航离视口顶部 16px，象牙白胶囊靠轻阴影与纸面分开。文章、主题、关于和 RSS 在手机上仍排成一行。当前页面或所属栏目以松墨绿标出。
- 首页先放简介与联系链接，再放精选、按年份倒序的文章列表和主题入口。列表用细线分隔日期、标题和摘要。主题卡片桌面两列，手机一列，有文章的主题可以点开。
- 文章标题下方保留日期。二级标题超过两个时显示目录。视口宽度超过 1100px 时目录吸附在正文右侧，其余宽度使用可展开的目录。锚点在桌面预留 112px，在手机预留 96px。
- 代码块用象牙白底、细线和 10px 圆角，行内代码用暖沙底。表格和代码块可单独横向滚动。引用用细灰线和次要文字。文末保留更新、纠错、主题、相关文章和上下篇导航。
- 主题详情保留导读与文章列表。关于页和错误页沿用同一正文栏。全站页脚左侧放站点名和简介，右侧列站内入口、GitHub 和 X。短页的页脚贴住视口底部。
- 页面使用 `lang="zh-CN"`，正文与导航由静态 HTML 输出。保留键盘焦点，正文链接带下划线。首页不设大横幅，装饰不使用表情、彩色卡片边条或动效。

## 构建字体

`npm run fonts` 从 GitHub 获取两份源字体，先校验 SHA-256，再缓存到 `.cache/fonts/`。屏显臻宋和思源宋体都按 SIL OFL 1.1 分发，授权文本随站点放在 `public/fonts/`。[屏显臻宋源文件](https://github.com/airinghost/clear-han-serif-subset/tree/main/ttf) · [思源宋体源文件](https://github.com/adobe-fonts/source-han-serif/tree/release/OTF/SimplifiedChinese)

脚本遍历 `src/` 和 `content/` 的 UTF-8 文本，解码 HTML 实体，收集不重复的非 ASCII 字符，并补齐常用中文标点。`subset-font` 在 Node 中生成两份同源 WOFF2，内部家族名为 Blog Serif SC。字表、构建脚本和依赖锁文件共同决定缓存签名。签名与产物哈希一致时复用已有子集。

两个字体写到 `public/fonts/`。清单 `src/generated/font-manifest.json` 保存裁切字表、字重和各文件的内容哈希。每页的预加载和字体声明共用同一条带版本参数的地址。原始字体、子集和清单均由构建生成，Git 只保留代码和授权文本。

`npm run dev` 启动前准备字体。编辑期间若引入新字，可重跑 `npm run fonts`。`npm run build` 自动裁切，再对全部成品 HTML 的汉字、弯双引号和省略号逐一核对输入字表和两份 WOFF2 的字符映射。`npm run check:fonts` 可单独复查。GitHub Actions 缓存源字体。

## 分享图

运行 `npm run og` 更新 `public/og/` 的默认图与文章封面。文章沿用已有的 `cover` 分行，封面文案规则见[标题与封面规范](title-cover-intro.md)。PNG 随仓库保存，页面的 Open Graph 和 X 卡片共用一张图。

画布固定为 1200×630px，羊皮纸底色为 `#fbfaf6`，左上站点标识为 30px 松墨绿 `#1a6840`，标题为 84px 暖炭黑 `#363433`。文字距左侧 96px。渲染器直接使用缓存的思源宋体 SC SemiBold，固定字形和分行，无需安装系统字体。留白承担层次，封面不加渐变、表情或截图。
