几条共同点：

- 中文正文 16.5–18px，行高 1.75–1.9，正文栏 680–760px，每行大约 38–44 个汉字。

- 文章页顶部信息少，正文开始得早；长文有目录。

## 排版

| 项目 | 取值 |
| --- | --- |
| 正文字号 | 17px，手机 16px |
| 行高 | 1.85 |
| 正文栏宽 | 最大 720px，约 42 个汉字一行；表格和代码块最大 860px |
| 段落间距 | 1em |
| 对齐 | 左对齐，不两端对齐 |
| 正文字体 | `-apple-system, "SF Pro Text", "PingFang SC", "Hiragino Sans GB", "Noto Sans SC", "Microsoft YaHei", sans-serif` |
| 代码字体 | `"SF Mono", "JetBrains Mono", Menlo, Consolas, monospace`，14px |
| 文字颜色 | 正文 `#1f2328`，次要信息 `#59636e` |
| 背景 | `#ffffff`；深色模式 `#0d1117`、正文 `#e6edf3` |
| 强调色 | 只用一种，用于链接：`#0969da`，深色模式 `#4493f8` |
| 标题 | H1 32px，H2 24px，H3 19px；字重 600；H2 上方留 2.2em |

不加载网络字体。中文字体文件太大，系统字体在 macOS、Windows 和手机上都够用。

## 首页

首页结构：

1. 站点名和导航：文章、主题、关于、RSS。
2. 两句简介：我是谁、这里写什么。例如“我是 SunSky，在做 AI Agent 工程。这里记录我读源码、做实验和做项目时的判断。”下面一行放 GitHub 和 X 链接。
3. 精选 3 篇：标题加一句描述。
4. 全部文章按年份分组，每条一行：日期、标题，下面一行灰色描述。
5. 主题入口：5 个主题，每个写一句它讲什么。

首页的 `title` 写成“SunSky 的 AI Agent 工程笔记”，描述里写清主题，方便搜索作者名和主题的人找到。

## 文章页

```text
站点名                         文章  主题  关于
────────────────────────────────────────────
DeepSeek SuperAgent 是什么？从源码看……       ┊ 目录
2026-11-01 · 源码解读 · 约 9 分钟 · 读的是 6337fc8 ┊ DeepSeek SuperAgent 是什么
                                              ┊ SuperAgent 架构
正文……                                         ┊ 谁的消息算命令
                                              ┊ ……
```

- 标题下一行元信息：日期、文章类型、阅读时长、证据等级（读源码、做过实验、项目里用过）。
- 宽度大于 1200px 时目录放在正文右侧并跟随滚动；窄屏时目录收进标题下方的可展开块。
- 源码对照表用普通表格，第一列文件名用等宽字体并链接到固定提交。
- 文末依次放：更新记录、“首发于本站，平台版本见……”、2–3 篇相关文章、上一篇和下一篇。
- 不放评论系统。讨论引导到 GitHub Discussions 或 X，减少脚本和维护。

## 主题页和关于页

- 主题页：一段原创导读、推荐阅读顺序、该主题全部文章。导读写这个主题解决什么问题，不只是列表。
- 关于页：我做什么、为什么写、文章的证据等级怎么理解、AI 辅助写作的说明、联系方式（GitHub、X）。这一页也是面试官最可能点开的页面。

## 分享图（OG 图）

每篇文章构建时自动生成一张 1200×630 的 PNG：

- 白底黑字，左上角站点名，中间是 [title-cover-intro.md](title-cover-intro.md) 定下的封面文字，3 行，每行最多 6 个字。
- 字号不小于 72px，留白不少于 80px。
- 不放渐变、表情、图标和截图。
- 同一张图也用作掘金、知乎的头图和 X 配图；平台要求的尺寸不同时，只改画布大小，文字不变。

## 不做的样式

以下是 AI 生成页面常见的套路，本站不用：大面积渐变背景、表情符号作图标、带彩色左边框的提示卡片、玻璃拟态、每段配插图、首页大横幅、动效和视差滚动。

## 可访问性和性能

- 页面 `lang="zh-CN"`。
- 文字和背景对比度不低于 4.5:1。
- 图片有替代文本；图里的文字在正文里也写一遍。
- 首页和文章页不依赖客户端 JS 渲染；除统计脚本外不加第三方脚本。
- 手机上横向不滚动，表格和代码块单独横向滚动。
