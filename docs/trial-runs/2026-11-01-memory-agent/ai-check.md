# AI 写作特征检测报告（dbs-ai-check）

按 `~/.gemini/dbskill/skills/dbs-ai-check/SKILL.md` 的报告格式，只诊断，不改写。体裁判断：技术说明文。

**命中 4 处**

**第 1 处**

> 长期记忆还要回答另外几个问题：同一件事变了以后，旧说法怎么办？证据不够时要不要答？用户要求删除时，怎么确认真的删干净了？

连续三个反问，长度和句式差不多，读起来像清单。三个问题都是正文真的会回答的，所以不算空话，但节奏太整齐。
`特征 #3 匀速排比 ⚠️`

**第 2 处**

> 问题出在存储层：它不知道第二句话替换了第一句。

每个小节都用一句结论收尾，这是其中一处。单看没问题，全文多处这样收，会显得每段都在“点题”。
`特征 #13 每个段落都有收束金句 💡`

**第 3 处**

> 如果你在做 Agent 长期记忆，可以先问自己三个问题：同一件事变了怎么办，证据不够时怎么办，用户要求删除时怎么证明。向量库只回答了“怎么找”。

结尾把开头的三个问题又说了一遍，再加一句金句。删掉这一段，文章在“边界与未解决问题”那里已经结束了。
`特征 #21 结尾「你值得」式祝福 ⚠️`

**第 4 处**

> 这个检查是确定性的，不靠模型自觉。

“不靠模型自觉”是在预先反驳一个读者没提的疑问。可以留，但要确认这是作者真的想强调的点。
`特征 #1 堵住所有反驳 💡`

**总结**：最明显的是首尾呼应的三连问。正文的事实和边界写得具体，没有夸大。

以上是检测结果，不涉及修改。作者决定是否修改、怎么改。
