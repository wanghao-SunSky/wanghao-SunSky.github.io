# 平台版本说明

| 平台 | 文件 | 和网站正文的差别 |
| --- | --- | --- |
| 掘金 | 用网站正文 `../article.md`，去掉 front matter | 开头加一行“首发于 wanghao-sunsky.github.io”；文末放网站和仓库链接；标签选“AI”“后端”“LLM” |
| CSDN | 同上 | 文章类型选“原创”；文末只放一条网站链接，不放课程或付费内容 |
| 知乎 | [zhihu.md](zhihu.md) | 改成回答问题的形式，篇幅约为正文的一半，只放一条链接 |
| X | [x.md](x.md) | 4 条串推，链接只在最后一条 |

掘金和 CSDN 直接用全文，因为它们的读者是来搜具体技术问题的，节选版读不完整。代价是平台页面可能在搜索结果里排在网站前面，见 [seo-distribution.md](../../../seo-distribution.md) 的“平台版本与重复内容”。
