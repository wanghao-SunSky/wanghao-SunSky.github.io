1/
给 Agent 加长期记忆，只存向量库会出一个很具体的问题：

用户说“评审 11 月 10 日”，后来又说“改到 12 日”。两句都会被检索出来，相似度差不多，模型可能答混。

向量库只管“找相似”，不知道哪句话已经过时。

2/
我在开源 Demo 里让写入多一步：模型把新事实和已有事实比较，只能选新增、重复确认、替换三种操作。

替换时旧版本不删，标为作废、写上结束时间，连成版本链。拿不准就选新增，因为错误替换比多存一条更难发现。

3/
回答时模型必须给出引用的记忆编号，代码检查编号是否来自本次检索，不是就丢掉，丢完为空就弃答。

删除时删整条版本链，再用被删内容做关键词和向量检索，命中必须为 0。
